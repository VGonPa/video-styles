# Third-party notices — terminal-dashboard

## Fira Code (font, `fonts/FiraCode-normal-400-latin.woff2`)

Copyright 2014-2020 The Fira Code Project Authors, from Google Fonts, SIL Open Font License 1.1 (no Reserved Font Name). The variable `latin` subset serves every weight used (400 for body text, 600 for titles and key values). It sets all the letters, digits and punctuation on screen.

The box-drawing borders, block and eighth-block bars, shades, braille spinner, arrows and status symbols are drawn procedurally per character cell, as modern terminal emulators do; the block-letter pixel font, the dashboard, its data and the synthesized audio are original. The look is inspired by text-based terminal dashboards in general; no existing interface is reproduced.
